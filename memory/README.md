# Memory layers

| Layer | Where | What it remembers |
|---|---|---|
| Rules | memory/<channel>/rules.md | The channel bible. Rarely changes. |
| Lessons | memory/<channel>/lessons.md | What went wrong or right. Agents read it before every job. |
| Decisions | memory/<channel>/decisions.md | Every choice you make in the Studio (written automatically). |
| Live state | data/projects/<id>/project.json | Where each song/episode is right now. |
| Performance | data/stats/<channel>.json | YouTube numbers over time (Settings → YouTube key). |
| History | git | Every change, dated. Push to your private GitHub repo. |
